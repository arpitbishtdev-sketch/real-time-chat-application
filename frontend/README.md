# Frontend — Real-Time Chat Application

React + Vite client for the chat app. See the [repository root README](../README.md) for prerequisites, setup, and the full dev/build/test command reference, and `FRONTEND.md` for the architecture and design-system decisions behind this package.

## Scripts

- `npm run dev` — Vite dev server (proxies `/api` and `/socket.io` to the backend)
- `npm run build` — production build, output to `dist/` (served by the backend in production)
- `npm test` — Vitest suite
- `npm run lint` — ESLint
- `npm run format` — Prettier write
